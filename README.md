# Globus-College-of-IT-Management

This project is a part of my NIELIT O-Level (IT) course. It is a responsive educational institute website of my pursuing institute Globus College of IT Management which includes different sections like academics, admission, facilities, online quiz, contact details and more.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* W3.CSS Framework

## Features

* Responsive design for desktop and mobile devices
* Home, Academics, Admission, Facilities, Online-Quiz, Contact 
* Embedded social media links
* Interactive navigation and user-friendly interface

## Project Background

As an Electrical and Instrumentation Engineering student, I primarily work on hardware-based projects and laboratory experiments. I chose a web development project for my O-Level submission so that, I can revise and apply the concepts, I've learned during the course.
